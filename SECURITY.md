# Security

This public repository contains application code and synthetic tests. It excludes operator sessions, bot tokens, wallet seed phrases, production databases and user exports.

Use your own deployment credentials. Keep environment files private. Never log Telegram initData, authorization headers, operator sessions or wallet secrets. A new deployment starts with empty storage; never copy sample credentials into production.

Report a suspected vulnerability privately to the repository owner through GitHub rather than posting credentials or player details in an issue.
