# Турниры 1×1 на DMX — проект первого запуска

DMX ведёт регистрацию, сетку, баланс и награды. Сама игра проходит на серверах
Pixel World в закрытой комнате. Наше приложение не запускает игровой сервер
и не передаёт движения, стрельбу или игровой видеопоток.

## Что подтверждено

Официальный клиент использует matchmaking/private/create и matchmaking/code/join.
Чтение matchmaking/private/config вернуло допустимые лимиты людей 4, 8, 30
и длительности матчей 240, 480, 720, 1200 секунд. Лимит ровно 2 не объявлен.
Поэтому перед запуском надо проверить комнату с двумя приглашёнными игроками:
старт в таком составе, отсутствие ботов и посторонних, выбранную карту/режим.
Автоматическое создание комнат приложением пока не реализовано. Во время
исследования комнаты не создавались и матчи не запускались.

API /stat/history относится к вошедшему игровому аккаунту. Подтверждённого
публичного результата заданного private match_id с UUID обоих участников,
итоговым счётом и победителем пока нет. Дневная таблица, клановый вклад
и скриншот сами по себе не доказывают исход конкретного 1×1.

## Первый турнир

Предлагаемый формат: 8 участников, выбывание после поражения, 7 дуэлей,
ограниченное число одновременно активных комнат. Вход бесплатный,
награды из заранее выделенного фонда организатора. Размеры призов и правила
распределения согласуются вместе с экономикой DMX; суммы не назначены.
Начисления в действующем приложении остаются выключены.

Организатор создаёт комнату и передаёт код только участникам пары.
Участники подтверждают готовность. Если результат не подтверждается игровым
источником, организатор рассматривает матч; автоматической выплаты нет.
Нужно заранее согласовать ничью, обрыв соединения, неявку, постороннего в
комнате, апелляцию и срок фиксации результата.

У каждого участника один закреплённый игровой UUID и один Telegram ID.
Пользователь выбрал привязку только по ID, без отдельной проверки владения.
Один игровой ID закрепляется за одним Telegram ID, и один Telegram ID — за
одним игровым ID. Отключение и повторный вход не освобождают эту связь.
Ввод ID подтверждает публичные данные; спорные привязки разбираются вручную.

## Позже: дуэли со вступительным взносом

До регистрации сервер атомарно резервирует DMX обоих игроков. Одну сумму
нельзя одновременно потратить в двух матчах. После подтверждённого результата
сервер один раз распределяет приз; повторный callback не начисляет его снова.
Отмена возвращает резерв один раз. Клиент не присылает доверенный баланс,
сумму награды или победителя.

Для этого требуется журнал операций в базе с транзакциями и уникальными
ключами матчей/выплат. Текущие JSON-файлы одного процесса годятся для
предпросмотра, но не заменяют такую базу при турнирных ставках и масштабировании.
Сначала DMX остаются внутренними очками приложения.

## Нагрузка и размещение

Списки и код комнат отдаёт сервер приложения, бои обслуживает Pixel World.
Запросы статистики объединяются по клану: один список участников можно
использовать сразу для всех зарегистрированных игроков этого клана.
Расписание и результаты карт кешируются; фоновая проверка не перечитывает
личные day/week/month таблицы для каждого пользователя.

Для постоянного турнира нужны постоянный адрес и сервер с базой, статические
ресурсы через CDN, очередь проверок результата, предел активных комнат,
ограничение частоты запросов и измерение нагрузки. Текущий Cloudflare Quick
Tunnel зависит от включённого компьютера и не является постоянным размещением.
Количество одновременно активных боёв следует увеличивать после замеров,
а не обещать неограниченное число участников.

## Что реализовано в приложении

Раздел «Турниры»: организатор открывает регистрацию на 4 или 8 мест, задаёт
карту, правила и лимит одной/двух одновременно активных комнат. После заполнения
мест сервер случайно формирует сетку. Организатор создаёт комнаты в самой игре
и вводит коды; в DMX они доступны только участникам пары и организатору.
Игроки подтверждают готовность. Организатор фиксирует счёт или техническую победу
с пояснением. Победитель проходит дальше; финал сохраняет чемпиона. Повторное
подтверждение завершённого матча отклоняется. Регистрация, сетка и результаты
сохраняются после перезапуска приложения.

Права создания турниров и фиксации результатов выданы только указанному
пользователем Telegram ID 900000001; другие участники не могут изменить их
передачей чужого ID в запросе. Коды комнат исключены из публичной выдачи.

Реальные турниры автоматически не создавались. Вступительные взносы и выплаты
DMX выключены. Игровая возможность честного 1×1 без ботов ещё требует проверки.
